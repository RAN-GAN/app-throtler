# Security policy

App Throttler runs a local VPN and sees the traffic of the apps you select, so security
reports are taken seriously.

Please do **not** open a public issue for a vulnerability. Report it privately through
GitHub's "Report a vulnerability" button on the Security tab of this repository, and include
steps to reproduce. You can expect a first reply within a few days.

The app has no server component and sends no data off the device. Saved packet captures and
exported setups are written only where you choose.
